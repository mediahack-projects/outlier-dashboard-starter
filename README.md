# Outlier dashboard starter

A SvelteKit (Svelte 5) starter for Outlier dashboards, deployed to Vercel.

```bash
npm install
npm run dev     # local preview at http://localhost:5173
npm run build   # check everything builds
```

- Brand tokens: `src/lib/styles/tokens.css`
- Data: `src/lib/data/` (example: `sample.csv`, 24 months)
- Charts: `src/lib/components/dashboard/`

See `CLAUDE.md` for the working rules.
